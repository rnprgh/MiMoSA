# Sample inputs

These inputs were supplied by Dubnau Lab, Rutgers University for the published
MiMoSA sample workflow:

- `01_Video/01_Sample_Video.mp4`: 100-frame viewing copy of the sample;
- `02_ND2_Frames/frame_001.tif` through `frame_100.tif`: 16-bit frames
  exported from the laboratory's ND2 recording with Fiji/ImageJ; and
- `FPS_Details.xlsx`: capture-rate and spatial-calibration metadata exported
  from the ND2 file.

The MP4 and TIFF files are stored with Git LFS. After cloning the repository,
run `git lfs pull` before opening the notebook.
